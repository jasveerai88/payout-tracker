# Contributing

Thanks for your interest! This is a small, local-first, Python-stdlib-only tool.

## How to help
- **Bug reports:** open an issue with your input file shape (no personal/financial data), the command you ran, and the output you got vs. expected.
- **Pull requests:** keep changes small, stdlib-only, and add or update a test in `tests/` for any behaviour change.
- **Run the tests first:** `python3 -m unittest discover -s tests -v` (stdlib only, no dependencies; the tests also run under pytest).

## Ground rules
- No network calls, no tracking, no new dependencies.
- A balance is never earnings, and a mention is never a lead without its evidence quote — don't weaken those rules.
